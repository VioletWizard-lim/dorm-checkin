# 시험용 파일

화면의 "파일 올리기" 기능을 시험해 볼 수 있는 예시 파일입니다. 모든 이름·학번은 가상의 시험용 데이터입니다(실제 학생 정보 없음).

| 파일 | 쓰는 곳 | 기대하는 결과 |
|---|---|---|
| `좌석_빈양식_1·2학년실_12x13.xlsx` | 좌석 배치판 → 편집 모드 → [좌석 일괄 등록] → [파일 올리기] | 12행×13열 빈 양식([빈 양식 받기 (엑셀)]으로 받은 것). 칸에 학번을 적어 올리면 같은 모양으로 배치 |
| `방과후_코딩반_출석부_월요일.pdf` | 방과후 일정 → 요일별 방과후 학생 등록 → 파일 불러오기 | 학년·반·번호 칸으로 학생을 찾고, "요일: 월요일"을 읽어 월요일을 자동으로 고름. 없는 반(전출 학생)은 안내 |
| `방과후_영어회화반_출석부_수요일.pdf` | 같은 곳 | 학번 칸으로 학생을 찾고, 머리글의 날짜(10/7·10/14) 또는 "수요일"로 수요일을 고름 |
| `방과후_독서토론반_명단_금요일.pdf` | 같은 곳 | 학번 없이 이름만 있는 명단 → 이름이 같은 학생으로 찾음(동명이인은 안내), "(금요일)"로 금요일을 고름 |
| `방과후_영어회화반_출석부_그림PDF(읽기불가).pdf` | 같은 곳 | 글자가 없는 그림(스캔) PDF → 읽을 수 없다는 안내가 나오는지 확인 |
